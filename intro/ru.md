LibreChat, OpenWebUI, SillyTavern и др.).

## Зачем это нужно (нейтральная формулировка)

Большинство ИИ-приложений строятся поверх биллинга по карте / фиату. Такая
инфраструктура не закрывает все сегменты: у части пользователей нет карты,
часть по умолчанию рассчитывается в крипте, а некоторые регионы не входят в
условия обслуживания основных провайдеров.

Этот endpoint — **платёжно-нейтральный маршрут**: по умолчанию USDT (крипта),
без карты, без KYC. Тот же совместимый с OpenAI интерфейс, который вы уже
используете. Он задуман как **дополнительный** маршрут рядом с вашими
текущими способами оплаты — не как их замена.

1. **Зарегистрируйтесь на шлюзе** → при регистрации выдаются тестовые кредиты

   качество.
2. **Напишите в TG:** `@mmrcle` — по вопросам *white-label* / оптовых поставок,
   тестовых ключей или интеграции.

## Частые вопросы

**Это замена моему текущему провайдеру?**
Нет. Это дополнительный совместимый с OpenAI маршрут для сегментов, которые не
закрывает ваш текущий стек (пользователи без карты, расчёт в крипте, регионы
вне условий вашего провайдера).

**Нужно ли переписывать код?**
Если ваш клиент говорит на API OpenAI — меняются только `base_url` и `api_key`.

**Как проверить до оплаты?**
Регистрация → тестовые кредиты → прогоните свои задачи через endpoint.
